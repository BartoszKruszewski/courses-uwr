# Zadanie 7

**Prompt (few-shot, format równoległy):**
```
Angielski: I like cats.
Polski: Lubię koty.
Angielski: The house is big.
Polski: Dom jest duży.
Angielski: <zdanie>
Polski:
```
Generację zatrzymujemy na końcu linii.

**Przykłady**
- poprawnie: „My brother has a dog.” → „Mój brat ma psa.”
- błędnie: „I can't bear it any longer.” → dosłownie: „Nie mogę niedźwiedzia…”,

**Użycie słownika EN–PL:**
Sprawdzamy czy słowa ze zdaniami, ktore chcemy przetlumaczyc maja odpowiedniki w slowniki i te co maja dodajemy jako tlumaczenia do prompta.
